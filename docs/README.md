# EcoVocação

Plataforma de Sustentabilidade, Empregabilidade e Impacto Social.

Projeto da disciplina Desenvolvimento Web (Prof. Paulo Fratta) - Fatec São Caetano do Sul.

## Objetivo

Site com 10 páginas em HTML5 e CSS3 sobre empregos verdes, economia solidária e inclusão de pessoas com deficiência.

## Entrega atual (MVP parcial)

- index.html (Home) com menu, rodapé, semântica HTML5 e acessibilidade
- css/style.css
- img/logo.svg
