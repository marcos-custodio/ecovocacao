Orçamento de hospedagem e domínio

Comparamos três hospedagens e três domínios antes de escolher

O que precisamos

Hoje o EcoVocação é um site estático (HTML, CSS, JavaScript, imagens, vídeo e áudio), com cerca de 2 MB. No futuro, queremos uma versão com PHP e banco de dados MySQL para o portal de vagas. Então a hospedagem precisa:

  • ter HTTPS (cadeado de segurança);
  • publicar o site direto do GitHub;
  • ser barata ou gratuita para um projeto acadêmico;
  • conseguir rodar PHP e MySQL mais pra frente.

Nossa escolha

Hospedagem: Railway. Já usamos desde o MVP, o deploy acontece sozinho a cada commit no GitHub, o HTTPS é automático e ele vai aguentar o PHP com MySQL no futuro. Também dá para colocar um limite de gastos, então não existe risco de uma conta surpresa.

Domínio: Registro.br. É o registro oficial do .com.br, o preço é fixo (R$ 40 por ano) e não sobe na renovação.
